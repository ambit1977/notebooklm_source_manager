# 配布用パッケージ

Chrome ウェブストアでの公開が終わるまでの、暫定的な配布用です。

| ファイル | 用途 |
|---|---|
| `notebooklm-source-manager-1.2.41-unpacked.zip` | **配る場合はこちら。** 展開すると `notebooklm-source-manager-1.2.41/` フォルダができます |
| `notebooklm-source-manager-1.2.41-webstore.zip` | Chrome ウェブストアへのアップロード用（ZIP のルートに `manifest.json` がある形式） |

---

## インストール手順（受け取った方向け）

1. `notebooklm-source-manager-1.2.41-unpacked.zip` を展開します
   `notebooklm-source-manager-1.2.41` というフォルダができます。
   **このフォルダは削除しないでください。** Chrome はここを直接読み込み続けるため、
   消したり移動したりすると拡張機能が動かなくなります。

2. Chrome で `chrome://extensions` を開きます

3. 右上の **「デベロッパー モード」** をオンにします

4. 左上の **「パッケージ化されていない拡張機能を読み込む」** を押し、
   手順1で展開したフォルダを選びます

5. NotebookLM（https://notebooklm.google.com/）でノートブックを開き、
   ツールバーの拡張機能アイコンをクリックします

> ツールバーにアイコンが見当たらない場合は、パズルのピースのアイコンを押して
> 一覧から「NotebookLM ソース一括削除・管理ツール」をピン留めしてください。

---

## よくある質問

**Q. 「デベロッパーモードの拡張機能を無効にする」という警告が出ます**

A. ストア外から読み込んだ拡張機能に対して Chrome が毎回出す確認です。
「キャンセル」を選べば有効なまま使えます。ストア版が公開されれば出なくなります。

**Q. ソースの一覧が表示されません**

A. v1.2.41 では、拡張機能を読み込んだ直後でも自動で再接続するようにしています。
それでも表示されない場合は、画面上に原因と対処法が出るので、
案内に従って「ページを再読み込み」または「再試行」を押してください。

**Q. Chrome を再起動したら消えました**

A. 展開したフォルダが移動・削除されていないか確認してください。

## 安全性について

- 処理はすべてブラウザ内で完結し、ソースの内容やタイトルを外部に送信しません
- アクセスするのは `notebooklm.google.com` のページのみです
- ソースコードは公開しています: https://github.com/ambit1977/notebooklm_source_manager

**削除は取り消せません。** 実行前に選択内容をご確認ください。
