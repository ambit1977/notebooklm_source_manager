# Screenshot and Media Guide for Chrome Web Store

This file lists recommended screenshots, captions (EN/JA), filenames, and capture instructions for the NotebookLM extension listing.

Chrome Web Store recommended image sizes:
- Promo image (optional): 440 × 280 px
- Screenshot: 1280 × 800 px (or similar landscape); at least 640 px wide
- Icon sizes: 128 × 128 px (already in repo)

Use PNG for screenshots, and keep UI chrome minimal. Prefer light background for clarity.

## Images to prepare

1) Screenshot 1 — Filter / main window
- Filename: `screenshot-filter-1280x800.png`
- EN caption: "Filter window — select sources to delete or manage"
- JA caption: "フィルターウィンドウ — 削除や管理対象を選択"
- Capture: Show the filter popup with several sources listed, multiple checkboxes checked, and the top controls visible (filter input, sort, source-type dropdown).
- Notes: Emphasize multi-selection UI and the delete button in the toolbar.

2) Screenshot 2 — Bulk delete confirmation
- Filename: `screenshot-delete-confirm-1280x800.png`
- EN caption: "Bulk delete confirmation — irreversible action with review"
- JA caption: "一括削除の確認 — 実行前に対象を確認できます"
- Capture: Show the confirmation dialog/modal with the number of items to be deleted.
- Notes: Use a highlighted selection and modal centered.

3) Screenshot 3 — Duplicate check / results
- Filename: `screenshot-duplicate-1280x800.png`
- EN caption: "Duplicate detection — find and handle duplicates"
- JA caption: "重複検出 — 類似するソースを検出して整理"
- Capture: Show duplicate detection UI listing duplicates and actions (merge/keep/delete).
- Notes: If merge isn't implemented, show the identify-and-delete flow.

4) Screenshot 4 — YouTube batch add UI
- Filename: `screenshot-yt-batch-1280x800.png`
- EN caption: "YouTube batch add — paste multiple links to add sources"
- JA caption: "YouTube 一括追加 — 複数リンクを貼って一括追加"
- Capture: Show the YouTube textarea with a few pasted links and the Add button.

5) Screenshot 5 — Settings or small help overlay
- Filename: `screenshot-settings-1280x800.png`
- EN caption: "Settings & help — understand permissions and usage"
- JA caption: "設定とヘルプ — 権限と使い方の説明"
- Capture: Show a short help text or settings panel indicating local processing and permissions.
