# NotebookLM Source Manager

Welcome to the public documentation for the NotebookLM Source Manager Chrome extension.

This site provides:

- **Tool overview** — what the extension does and why it exists
- **Installation steps** — how to build and load the extension
- **Usage guide** — how to use the filter, delete, rename, and screenshot functions
- **Troubleshooting (Q&A)** — common problems and solutions
- **Technical information** — versions, build, packaging, and release flow

## Publish this site

To publish this content with GitHub Pages:

1. Push this repository to GitHub.
2. In the repository settings, set Pages source to the `main` branch and the `/docs` folder.
3. Wait a few minutes for GitHub to build the site.
4. The site URL will be:

   `https://ambit1977.github.io/notebooklm_source_manager/`
