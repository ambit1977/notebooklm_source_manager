導入方法

開発版パッケージを Chrome に読み込む手順です。5分ほどで終わります。

どちらを使うか

Chrome ウェブストア版開発版パッケージ
入手ストアから1クリックZIP をダウンロードして読み込み
更新自動手動（新しい ZIP に入れ替え）
最新の修正審査後に反映（数日〜数週間）すぐ使える
起動時の警告なしデベロッパーモードの警告が出ることがある

急がないなら ウェブストア版 をおすすめします。修正をすぐ試したい場合は、以下の手順で開発版をお使いください。

開発版パッケージの導入手順

ZIP をダウンロード（v1.2.43）

  1. ZIP を展開する ダウンロードした ZIP をダブルクリックすると、notebooklm-source-manager-v1.2.43 というフォルダができます。
  2. フォルダを置き場所に移動する 書類フォルダなど、あとから消さない場所に移動してください。
  3. 拡張機能ページを開く Chrome のアドレスバーに chrome://extensions と入力して開きます。
  4. デベロッパーモードをオンにする 画面右上のスイッチをオンにします。オンにすると左上にボタンが3つ表示されます。
  5. フォルダを読み込む 「パッケージ化されていない拡張機能を読み込む」をクリックし、手順2で置いたフォルダを選択します。
    ※ ZIP ファイルではなく、展開してできたフォルダを選んでください。
  6. ツールバーに固定する ツールバーのパズルのピースのアイコンをクリックし、この拡張機能のピンをオンにすると、いつでも押せるようになります。

読み込んだフォルダは消さないでください。 Chrome はフォルダの中身を毎回読み込むため、フォルダを削除したり移動したりすると拡張機能も動かなくなります。ダウンロードフォルダに置いたままにせず、消さない場所へ移動しておくのが安全です。

ウェブストア版と併用する場合。 どちらも読み込んでいると、ツールバーに同じアイコンが2つ並びます。混乱を避けるため、chrome://extensions でどちらか一方をオフにしておくことをおすすめします。

更新のしかた

  1. 新しい ZIP をダウンロードして展開する
  2. 古いフォルダの中身を差し替える古いフォルダを削除し、新しいフォルダを同じ場所に置きます。
  3. 再読み込みするchrome://extensions で、この拡張機能のカードにある更新（⟳）アイコンをクリックします。フォルダ名が変わった場合は、いったん削除してから読み込み直してください。

困ったときは

Chrome の起動時に「デベロッパー モードの拡張機能を無効にする」と出る

開発版を読み込んでいると Chrome が毎回出す警告です。そのまま閉じれば拡張機能は動き続けます。この表示が煩わしい場合は、ウェブストア版に切り替えてください。

拡張機能アイコンを押してもウィンドウが開かない

chrome://extensions でこの拡張機能がオンになっているか、エラー表示が出ていないかをご確認ください。

「NotebookLM のタブが見つかりません」と表示される

ノートブックの一覧画面ではなく、ノートブックを1つ開いた状態でアイコンをクリックしてください。NotebookLM は notebooklm.google.com と notebook.google.com のどちらかで開きますが、どちらにも対応しています。

「ページと通信できませんでした」と表示される

拡張機能を入れた直後・更新した直後は、その前から開いていたタブとつながらないことがあります。画面に出る「ページを再読み込み」ボタンを押すと復旧します。

ソースの一覧が空のまま出てこない

NotebookLM 側の読み込みが終わる前だと空になることがあります。「再試行」を押してください。それでも出てこない場合は、NotebookLM のタブを再読み込みしてからもう一度お試しください。
