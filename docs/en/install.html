Installation

How to load the developer build into Chrome. It takes about five minutes.

If you are not in a hurry, the Web Store version is the easier choice. Use the steps below when you want a fix that is still in review.

Installing the developer build

Download the ZIP (v1.2.44)

  1. Unzip the file Double-click the downloaded ZIP. You will get a folder named notebooklm-source-manager-v1.2.44.
  2. Move the folder somewhere permanent Your Documents folder is a good spot — anywhere you will not delete later.
  3. Open the extensions page Type chrome://extensions into the address bar and press Enter.
  4. Turn on Developer mode The toggle is at the top right. Three buttons appear at the top left once it is on.
  5. Load the folder Click Load unpacked and select the folder from step 2.
    Select the unzipped folder, not the ZIP file itself.
  6. Pin it to the toolbar Click the puzzle-piece icon in the toolbar and pin this extension so it is always one click away.

Do not delete the folder you loaded. Chrome reads its contents every time it starts, so deleting or moving the folder breaks the extension. Move it out of your Downloads folder to somewhere you will keep it.

Running it alongside the Web Store version. With both loaded you will see two identical icons in your toolbar. To avoid confusion, turn one of them off in chrome://extensions.

Updating

  1. Download and unzip the new ZIP
  2. Replace the old folderDelete the old folder and put the new one in the same place.
  3. Reload the extensionClick the reload (⟳) icon on the extension's card in chrome://extensions. If the folder name changed, remove the extension and load it again.

Troubleshooting

Chrome warns about "Disable developer mode extensions" at startup

Chrome shows this every time you have an unpacked extension loaded. Dismiss it and the extension keeps working. Switch to the Web Store version if the prompt bothers you.

Clicking the icon does not open a window

Check chrome://extensions to confirm the extension is enabled and that no error is shown on its card.

"No NotebookLM tab found"

Open an actual notebook — not the notebook list — before clicking the icon. Depending on your account, NotebookLM (officially Gemini Notebook) opens on either notebooklm.google.com or notebook.google.com; both are supported.

"Could not communicate with the page"

Right after installing or updating, the extension cannot reach tabs that were already open. Click Reload page in the message to recover.

The source list comes up empty

The list can come back empty if NotebookLM has not finished loading. Click Retry. If that does not help, reload the NotebookLM tab and try again.
