What it does

Bulk delete

Select sources with checkboxes and delete them in one go. Select-all included.

Filter first

Narrow by keyword (regex supported) or by type — PDF, website, YouTube, and more.

Abort mid-run

Stop a deletion while it is running, in case you picked the wrong set.

Duplicate check

Surface sources that share a title, so you can clean up repeated imports.

Batch rename

Paste old title,new title lines and rename everything at once.

Batch add YouTube

Paste share links one per line. Short links are normalized automatically.

Installing the developer build

  1. Download and unzipYou will get a folder named notebooklm-source-manager-v1.2.43.
  2. Move the folder somewhere permanentChrome reads this folder every time it starts, so do not leave it in Downloads and do not delete it later.
  3. Open chrome://extensionsType it into the address bar.
  4. Turn on Developer modeThe toggle is at the top right.
  5. Click "Load unpacked"Select the folder you unzipped — the folder, not the ZIP file.
  6. Pin it to the toolbarClick the puzzle-piece icon and pin this extension.

Chrome may show a "Disable developer mode extensions" warning on startup. You can dismiss it; the extension keeps working. Use the Web Store version if you would rather not see it.

Updating

Download the new ZIP, replace the old folder with the new one in the same location, then click the reload (⟳) icon on the extension's card in chrome://extensions. If the folder name changed, remove the extension and load it again.

How to use it

  1. Open a notebook in NotebookLMOpen an actual notebook, not the notebook list.
  2. Click the extension iconA separate window opens with your source list.
  3. Pick a modeDelete, batch add, or rename — switch with the tabs at the top.

Deleting

Tick the sources you want gone and click Delete selected sources. Use the title filter, the regex option, or the source-type dropdown first, then hit select-all — only the currently visible sources are selected. Click Abort deletion to stop a run in progress.

Deletion cannot be undone. NotebookLM has no undo for removed sources, so check your selection before you run it. Use Download CSV first if you want a record of what was there.

Batch rename

One pair per line, old title,new title. Wrap a title in double quotes if it contains a comma. Old titles are matched exactly — export the current list with Download CSV and edit that to be safe.

Batch adding YouTube

Paste share links one per line and click Add YouTube URLs. Short youtu.be links and playlist parameters are normalized automatically. Website bulk-add was removed because NotebookLM now offers it natively.

A note on speed

Deletion drives the actual NotebookLM UI, so large batches take time. Chrome also throttles background tabs, so keep the NotebookLM tab visible if you want it to run at full speed.

Privacy

  • Everything runs locally in your browser
  • Source titles and contents are never sent anywhere
  • The extension only accesses NotebookLM pages
  • It never touches your account credentials

Source code is on GitHub. Please report problems in Issues — this extension depends on NotebookLM's page structure, so Google's changes can temporarily break it.
