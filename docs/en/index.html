About the developer build. Every Web Store update goes through Google's review, which can take anywhere from a few days to a few weeks. If you want a fix right now, use the build on this page — it is the same code that was submitted to the store.

A note on the name. Google's official name for the product is Gemini Notebook. Most people still call it NotebookLM, so these pages use "NotebookLM" throughout — the two refer to the same product. The extension works on both notebooklm.google.com and notebook.google.com, since which domain you get depends on your account.

What it does

Bulk delete

Select sources with checkboxes and delete them in one go. Select-all is included.

Filter first, then delete

Narrow by keyword (regex supported) or by type — PDF, website, YouTube, and more.

Abort mid-run

Stop a deletion while it is running. Your safety net if you picked the wrong set.

Duplicate check

Surface sources that share a title, so you can clean up repeated imports.

Batch rename

Write old title,new title one pair per line and rename everything at once.

Batch add YouTube

Paste share links one per line. Short links are normalized automatically.

Get started in 3 steps

  1. Download and unzipUse the button above, then unzip the file.
  2. Load it into ChromeOpen chrome://extensions, turn on Developer mode, and load the unzipped folder.
  3. Use it in your notebookOpen a notebook, then click the extension icon in the toolbar.

Privacy

  • Everything runs locally in your browser
  • Source titles and contents are never sent anywhere
  • The extension only accesses NotebookLM pages
  • It never touches your account credentials or passwords

The source code is public on GitHub.

Deletion cannot be undone. NotebookLM has no undo for removed sources, so please check your selection before you run it. Exporting the list with "Download CSV" first gives you a record to fall back on.

Reporting problems

This extension works by driving the NotebookLM interface directly, so changes on Google's side can temporarily break it. If something stops working, please open an issue on GitHub — reports with a screenshot of the browser console are especially helpful.
