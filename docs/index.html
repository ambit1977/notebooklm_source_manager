名称について。 Google による正式名称は Gemini Notebook です。ただ「NotebookLM」の呼び方が定着しているため、このサイトでは NotebookLM と表記しています。どちらも同じ製品を指します。アカウントによって notebooklm.google.com と notebook.google.com のどちらで開くかが変わりますが、本拡張機能はどちらにも対応しています。

開発版パッケージについて。 ウェブストア版は更新のたびに Google の審査があり、公開まで数日〜数週間かかることがあります。修正をすぐ試したい場合は、このページの開発版をお使いください。中身はストアに申請しているものと同じです。

できること

ソースの一括削除

一覧からチェックで選んでまとめて削除。全選択にも対応しています。

絞り込んでから消す

キーワード（正規表現可）や種類（PDF・ウェブ・YouTube など）で絞り込めます。

削除の中断

実行中に止められます。押し間違えたときの保険になります。

重複チェック

同じタイトルのソースを検出。取り込みすぎた資料を整理できます。

一括リネーム

「変更前,変更後」を並べて書くだけで、まとめて名前を変更します。

YouTube の一括追加

リンクを1行ずつ貼るだけ。短縮リンクも自動で正規化します。

3ステップではじめる

  1. ダウンロードして展開上のボタンから ZIP を取得し、展開します。
  2. Chrome に読み込むchrome://extensions でデベロッパーモードをオンにして、展開したフォルダを読み込みます。
  3. NotebookLM で使うノートブックを開き、ツールバーの拡張機能アイコンをクリックします。

安全性について

  • 処理はすべてお使いのブラウザ内で完結します
  • ソースの内容やタイトルを外部に送信することはありません
  • アクセスするのは NotebookLM のページのみです
  • アカウント情報やパスワードにはアクセスしません

ソースコードは GitHub で公開しています。

削除は取り消せません。 NotebookLM 側に元に戻す機能がないため、実行前に選択内容をご確認ください。削除前に「CSVダウンロード」で一覧を控えておくと安心です。

不具合の報告

この拡張機能は NotebookLM の画面を操作して動作します。Google 側の変更で一時的に動かなくなることがあります。お気づきの点は GitHub の Issues までお知らせください。

本拡張機能は Google LLC の提供物ではなく、公式のものでもありません。
